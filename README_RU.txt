OneFriday Fitness v3

Что изменилось:
- Убран визуальный баг с цветной полосой: я убрал blur/backdrop-filter, conic-gradient и сложные прозрачные слои, которые могут глючить в Chrome на Samsung.
- Дизайн переделан под Samsung Galaxy S23/S23+ и Chrome: максимальная ширина 430 px, более крупные поля, карточки подходов вместо тесной таблицы.
- Подходы теперь удобнее отмечать одной рукой.
- Ачивки стали накопительными: они дают очки, очки складываются, от них зависит уровень.
- Добавлено больше забавных ачивок.
- Сохранена автоподстановка прошлых весов/повторов.
- Сохранены история, CSV, backup JSON и восстановление.
- Старые данные из v1/v2 приложение попробует подхватить автоматически.

Важно:
Если открывать приложение как content:// или file://, Chrome может не дать полноценную установку PWA.
Для нормальной установки на главный экран лучше открыть приложение через https-хостинг.
Но как локальная страница оно всё равно работает и хранит данные в браузере.
