MyFitness v6.0.0

Обновление на GitHub Pages
1. В том же репозитории и той же папке замените старые файлы файлами этого архива.
   Добавьте новый version.json. Не меняйте адрес сайта.
2. Не удаляйте данные сайта в Chrome. Статистика хранится на устройстве в localStorage.
3. На всякий случай до загрузки файлов откройте старое приложение → Запись → Скачать backup.
   Этот JSON не загружайте в GitHub.
4. Когда GitHub Pages опубликует файлы, откройте приложение и нажмите «Обновить».
   При переходе со старой v5 кнопки ещё не было: первый раз может понадобиться
   закрыть и заново открыть приложение или обновить страницу в Chrome.
5. Если старая версия упорно остаётся, откройте адрес сайта с /index.html?v=6.0.0
   в конце пути. После этого кнопка «Обновить» будет работать для новых версий.

Что изменилось
- Три более умеренные тренировки с 15 минутами кардио в конце.
- Выпады в ходьбе в день 2: один пробный подход без веса. Если колено реагирует,
  упражнение можно пропустить. В пятницу дополнительных выпадов нет.
- 15 минут кардио после зала трижды в неделю дают 45 минут. Для ориентира
  около 150 минут умеренного движения в неделю учитывайте также прогулки,
  танцы, велосипед и другие занятия. Не форсируйте нагрузку на колено.
- Новый светлый интерфейс и название MyFitness, ачивки удалены.
- Исправлены местная дата и дни недели (понедельник, среда, пятница).
- Сохранён прежний ключ onefriday_fitness_v4 и старые записи, включая упражнения,
  исключённые из нового плана. Резервная копия и экспорт CSV доступны в разделе «Запись».
- Обновление проверяет version.json, активирует новую версию и перезагружает приложение.

После первой загрузки проверьте историю, количество тренировочных дней и
резервную копию. Если название ярлыка Android сразу не поменялось, это может
быть особенностью обновления установленного ярлыка; данные приложения не очищайте.
