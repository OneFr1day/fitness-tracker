# MyFitness

Личный дневник тренировок: план на три дня, запись подходов, веса и повторов, история занятий и статистика прогресса. Работает в браузере и устанавливается на телефон как PWA.

[Открыть приложение](https://onefr1day.github.io/fitness-tracker/)

## Возможности

- Три дня тренировок с упражнениями, количеством подходов, временем отдыха и вариантами замены.
- Запись веса, повторов, времени или длительности кардио — в зависимости от упражнения.
- Отметки самочувствия: легко, нормально, тяжело, боль или пропуск.
- Предыдущие результаты рядом с упражнением. Сохранённые упражнения убираются из текущего списка и доступны в блоке «Выполнено сегодня».
- Ручная запись тренировок за выбранную дату.
- Статистика активности за 7 и 30 дней, результаты по упражнениям и история с фильтрами.
- Экспорт истории в CSV, резервная копия и восстановление из JSON.
- Работа без интернета после первого успешного открытия и установки офлайн-кэша.

## Данные

Приложение работает без регистрации и серверной базы. История хранится в localStorage браузера на устройстве. Данные не синхронизируются между устройствами; перенести их можно через JSON-копию в разделе «Запись».

## Дизайн

Знак M, тёмно-зелёный #152724, лаймовый #C6F36A и светлый фон #F6F7F2. SVG-логотип содержит контуры букв и не требует внешнего шрифта.

## Запуск и публикация

Статическое приложение на HTML, CSS и JavaScript. Сборка и установка зависимостей не нужны.

Для локального запуска из папки проекта:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Service Worker работает на localhost или HTTPS.

Для GitHub Pages все файлы проекта должны находиться в корне публикуемой ветки. Не переносите их в public/assets: приложение использует относительные пути.

## Обновление до 6.1.1

1. Распакуйте архив обновления.
2. В репозитории onefr1day/fitness-tracker выберите Add file → Upload files.
3. Загрузите все файлы из архива в корень репозитория, с заменой существующих файлов. Загружать сам ZIP не нужно.
4. Нажмите Commit changes и дождитесь завершения публикации GitHub Pages.
5. Откройте приложение и нажмите «Обновить». Под логотипом должна появиться версия 6.1.1.
